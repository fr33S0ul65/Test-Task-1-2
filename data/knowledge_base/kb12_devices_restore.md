# Using several devices and restoring purchases

You can use one MyTestBase account on several devices. Log in with the same method you used to sign up (email, Apple or Google).

If your subscription is not visible after logging in on a new device, open Profile → Settings → Restore purchases. This works only with the same Apple ID or Google account that was used for the original purchase.

Chat balance and chat history are linked to your MyTestBase account, not to the device.
