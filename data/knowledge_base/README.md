# База знань MyTestBase (симульована)

MyTestBase — вигаданий продукт: астрологічний застосунок з підписками й платними чатами з експертами, за тематикою схожий на Nebula. Статті імітують його довідковий центр для тестового завдання. Правила вигадані й не відображають політику жодної реальної компанії; адреса сайту — із зарезервованого домену `.example`.
